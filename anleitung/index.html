Dein eigenes Web-Projekt in 6 Schritten

Du bekommst eine eigene Adresse wie gewichttracker.skillusnow.de und baust dort mit deiner KI eine Webseite, ein kleines Tool oder ein Spiel. Keine Vorkenntnisse nötig – nimm dir beim ersten Mal etwa 20 Minuten Zeit.

Dein Computer:

Was du brauchst

  • Dein Skill-Me-Now-Konto (dieselbe E-Mail-Adresse wie im Campus). Mitmachen können nur Teilnehmende und das Team.
  • Einen Mac oder einen Windows-PC (Windows 10 oder 11).
  • Eine KI. Am einfachsten: Claude Code, Codex oder Cursor – die arbeiten direkt auf deinem Projekt. ChatGPT oder Claude im Browser gehen auch, dann kopierst du die Dateien selbst hoch (Schritt 6 B).

1 Das Terminal öffnen

Das Terminal ist ein Fenster, in das du Befehle tippst. Keine Sorge – du kopierst sie nur von hier.

Mac: Drücke ⌘ + Leertaste, tippe Terminal und drücke Enter.

Windows: Klicke auf Start, tippe PowerShell und öffne „Windows PowerShell“.

2 Deinen Schlüssel erzeugen

Statt eines Passworts nutzt du einen Schlüssel. Er besteht aus zwei Teilen: einem geheimen Teil, der auf deinem Computer bleibt, und einem öffentlichen Teil, den du uns gibst – wie ein Schloss, zu dem nur du den Schlüssel hast. Kopiere diesen Befehl ins Terminal und drücke Enter. Ersetze dein-name durch deinen Vornamen.

ssh-keygen -t ed25519 -f ~/.ssh/skillusnow -C "dein-name"
ssh-keygen -t ed25519 -f $env:USERPROFILE\.ssh\skillusnow -C "dein-name"

Kommt „ssh-keygen wurde nicht erkannt“? Dann: Einstellungen → System → Optionale Features → Feature hinzufügen → OpenSSH-Client installieren, PowerShell neu öffnen.

Das Terminal fragt nach einem Passwort (passphrase): Drücke einfach zweimal Enter, damit deine KI später ohne Nachfrage arbeiten kann.

🔒 Den geheimen Teil (die Datei skillusnow ohne .pub) gibst du niemals weiter – auch nicht an eine KI im Browser.

3 Den öffentlichen Teil kopieren

Dieser Befehl legt den öffentlichen Teil in deine Zwischenablage:

pbcopy < ~/.ssh/skillusnow.pub
Get-Content $env:USERPROFILE\.ssh\skillusnow.pub | Set-Clipboard

Er sieht ungefähr so aus: ssh-ed25519 AAAAC3Nza…lange Zeichenkette… dein-name. Ein / oder + darin ist normal.

4 Dein Projekt anlegen

  1. Öffne skillusnow.de/start und melde dich mit deiner Campus-E-Mail an. Du bekommst einen Code per Mail.
  2. Gib deinem Projekt einen Titel (daraus wird die Adresse) und beschreibe in einem Satz, was es können soll.
  3. Füge bei „SSH-Schlüssel“ den öffentlichen Teil ein (⌘/Strg + V).
  4. Lies die Nutzungsregeln, setze den Haken und klicke „Projekt anlegen“.

Danach siehst du deinen Projektnamen (z. B. p-gewichttracker) und einen fertigen Auftrag für deine KI. Pro Person sind 2 Projekte mit je 1 GB möglich.

5 Verbindung testen

Ersetze p-gewichttracker durch deinen Projektnamen:

ssh -i ~/.ssh/skillusnow p-gewichttracker@skillusnow.de

Beim ersten Mal fragt das Terminal „Are you sure you want to continue connecting?“ – tippe yes und Enter. Siehst du p-gewichttracker@skillusnow:~$, bist du drin. Mit exit kommst du wieder raus.

6 Mit deiner KI bauen

A · Claude Code, Codex oder Cursor

Diese KIs arbeiten direkt auf deinem Projekt:

  1. Starte die KI auf deinem Computer.
  2. Füge den Auftrag von skillusnow.de/start ein.
  3. Die KI verbindet sich, liest die Regeln (AGENTS.md) und baut deine Seite im Ordner www/.
  4. Öffne deine Adresse im Browser – jede Änderung ist sofort sichtbar.

Fragt die KI, ob sie einen Befehl ausführen darf, lies kurz mit und bestätige. So lernst du nebenbei, was passiert.

B · ChatGPT oder Claude im Browser

Diese KIs können nicht selbst auf den Server. Du lädst die Dateien hoch:

  1. Bitte die KI: „Baue mir eine Webseite: … Gib mir alle Dateien einzeln aus, die Startseite heißt index.html.“
  2. Lege auf deinem Computer einen Ordner mein-projekt an und speichere die Dateien dort.
  3. Öffne das Terminal in diesem Ordner und lade alles hoch:
scp -i ~/.ssh/skillusnow -r mein-projekt/. p-gewichttracker@skillusnow.de:www/

Gibt es eine ältere Datei mit gleichem Namen, wird sie überschrieben.

Wenn etwas nicht klappt

„Permission denied (publickey)“
Der Schlüssel passt nicht. Prüfe den Projektnamen (mit p- davor) und ob du in Schritt 3 den Inhalt der .pub-Datei kopiert hast. Hilft das nicht, melde dich beim Team.
Ich sehe meine Änderung nicht
Lade die Seite ohne Zwischenspeicher neu: Mac ⌘ + ⇧ + R, Windows Strg + F5.
Meine KI hat etwas kaputt gemacht
Kein Problem: Jede Nacht wird alles gesichert. Melde dich beim Team, wir holen den Stand vom Vortag zurück.
Kann ich Server-Programme, Datenbanken oder Logins bauen?
Hier laufen nur Webseiten (HTML, CSS, JavaScript). Daten kannst du im Browser speichern (localStorage). Alles läuft also beim Besucher – das reicht für erstaunlich viele Tools und Spiele.

Die wichtigsten Regeln

Dein Projekt ist öffentlich. Nichts Illegales, auf Urheberrechte achten (selbst gemacht, KI-generiert oder frei nutzbar), keine Daten anderer ohne Einwilligung, keine Passwörter oder Schlüssel in deinen Dateien. Die vollständigen Regeln bestätigst du beim Anlegen.
